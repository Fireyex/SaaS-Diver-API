# 🚀 SaaS Diver API
Sistema profesional de gestión de suscripciones para modelos de negocio SaaS.

## 🛠 Tecnologías
- **.NET 9** (Web API)
- **Entity Framework Core** (SQL Server)
- **Patrón de Repositorio/Servicio**
- **Swagger** para documentación

## ⚙️ Instalación
1. Clonar el repositorio.
2. Actualizar la cadena de conexión en `appsettings.json`.
3. Ejecutar `Update-Database` en la Consola del Administrador de Paquetes.
